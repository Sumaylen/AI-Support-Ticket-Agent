# Changing an Order After Purchase

Shipping address changes can be made only while an order is in "Processing" status. Once an order has shipped, the address cannot be changed, and the customer should instead contact the shipping carrier directly or arrange to intercept the package if the carrier allows it.

Adding or removing items from an existing order is not supported. A customer who wants to add an item must place a new, separate order. A customer who wants to remove an item must wait for delivery and process a partial return.

Changing a payment method on an order that has already been placed is not possible. If a payment fails after the order is placed, the customer will be prompted to provide a new payment method before the order can proceed.
